# BRAT for VS Code

Syntax highlighting, snippets and bracket rules for `.brat` and `.bri` files.

The TextMate grammar covers `fn`, `struct`, `enum`, `trait`, `impl`, `arena`,
`own`, `par for`, `extern`, `export fn`, `ptr[T]`, `move`, `mut` and `?`.

To try it, open `editors/vscode` in VS Code and press `F5`, or copy the folder
to `~/.vscode/extensions/brat-lang`.
